# 사대보험 (sabohum)

퇴직 전후 건강보험 선택을 공식 기준과 공개된 검증 이력으로 설명하는 민간 참고 도구.

경쟁 서비스에도 피부양자·임의계속·지역가입자 비교 기능이 있으므로, 기준체크는 기능의
존재보다 단계별 근거·공식 대조 범위·갱신 이력·한계 공개를 경쟁력으로 삼는다.

## 시작하기

```bash
npm install
npm run dev       # 개발 서버
npm test          # 판정·보험료 로직 136개 테스트
npm run verify    # 타입체크 + 테스트 + 빌드 한 번에
```

### 프로덕션 결과 확인

`output: 'export'` 설정이므로 **`next start` 를 쓸 수 없습니다.**
빌드 결과인 `out/` 을 정적 서버로 띄웁니다.

```bash
npm run build     # out/ 생성
npm run preview   # out/ 을 정적 서버로 서빙
# 또는 한 번에
npm start
```

이 제약을 포함해 `output: 'export'` 때문에 생기는 세 가지 주의사항은
`next.config.mjs` 주석에 적어뒀습니다.

## 지켜야 할 규칙 5개

**1. 숫자를 코드에 직접 쓰지 않는다.**

요건과 요율은 매년 바뀝니다. 기존 계산기들이 낡아서 죽은 이유가 이것입니다.
모든 기준값은 `src/lib/constants/2026.ts`에 있고, 로직 파일에는 숫자 리터럴이 없습니다.

새 연도가 오면 `2026.ts`를 복사해 `2027.ts`를 만드세요.

**2. 로직을 UI에 넣지 않는다.**

`judge.ts`와 `regional.ts`는 순수 함수이고 React를 import하지 않습니다.
법령이 바뀔 때 컴포넌트를 뒤지게 되면 유지보수를 포기하게 됩니다.

**3. 경로는 `routes.ts`에만 쓴다.**

페이지를 추가할 때 sitemap 등록을 잊는 게 가장 흔한 실수입니다.
`ROUTES`에 등록하고 `ready: true`로 바꾸면 sitemap이 자동으로 따라옵니다.
컴포넌트에 경로 문자열을 직접 쓰지 마세요.

**4. 결과에는 항상 근거와 기준 연도를 붙인다.**

이 사이트의 자산은 신뢰입니다. 모든 `StepResult`에 `basis`가 있고
`JudgeResult`에 `year`가 있습니다. UI에서 빼지 마세요.

**5. `layout.tsx`에서 임의 상수를 export 하지 않는다.**

Next.js App Router는 layout 파일의 export 필드를 제한합니다.
`SITE` 같은 상수를 여기 두면 빌드가 실패합니다. `src/lib/site.ts`를 쓰세요.

## 현재 남은 확인 과제

**① 검색 색인 처리 결과 확인**

Google Search Console과 네이버 서치어드바이저에 사이트·sitemap·핵심 URL의 수집/색인을
요청했습니다. 신청과 실제 색인 완료는 다르므로 1주 단위로 색인 상태·제외 사유·선택
canonical을 확인해야 합니다.

지역보험료 계산은 2026-08-03 공단 공식 모의계산 13건과 대조했고,
`VERIFIED_AGAINST_NHIS = true`로 기록되어 있습니다. 피부양자 판정은 공단 공개 안내·
시행규칙 기준 대표 사례 8건을 자체 재현했으며, 로그인 모의계산·실제 처리 결과 대조는
별도 과제입니다.

**② 운영 지표 누적 확인**

GA4 핵심 이벤트는 실시간 수신까지 확인했습니다. Vercel Speed Insights는 연결·배포를
완료했으므로 실제 Core Web Vitals 데이터가 누적되는지 확인하고, 내부 테스트 트래픽을
분리하는 운영 기준을 정해야 합니다.

> 참고: 피부양자 최종 자격·지역보험료 고지액·임의계속가입 신청 가능 여부는
> 국민건강보험공단의 최신 안내와 개별 심사가 우선입니다.

## 놓치기 쉬운 함정 3개

작업 중 실제로 밟았던 것들입니다. 같은 곳을 또 밟지 않도록 적어둡니다.

**① `layout.tsx`에서 임의 상수를 export 하면 빌드가 깨진다**

Next.js App Router는 layout 파일의 export 필드를 제한합니다. → `src/lib/site.ts`

**② `'use client'` 모듈의 함수를 서버 컴포넌트에서 호출하면 빌드가 깨진다**

`won()` 같은 포맷 함수를 `components/ui.tsx`에 두면
`page.tsx`의 `metadata`·FAQ 생성에서 호출할 수 없습니다. → `src/lib/format.ts`

**③ `output: 'export'`에서 메타데이터 라우트는 `force-static`이 필수**

`robots.ts`·`sitemap.ts`에 `export const dynamic = 'force-static'`이 없으면
"Collecting page data" 단계에서 실패합니다.
