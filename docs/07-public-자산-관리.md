# 공개 자산 관리

`public/`의 파일은 정적 빌드 시 `out/` 루트로 그대로 복사된다.
따라서 이 폴더에는 브라우저가 직접 요청해야 하는 자산만 둔다.

## 허용되는 파일

- `logo.svg`와 `og/*.png`처럼 실제 페이지가 참조하는 정적 자산
- 검색엔진 소유 확인 파일이나 승인 후 사용하는 `ads.txt`

내부 문서·검토용 스크립트·빌드용 산출물은 `public/`에 두지 않는다. 문서를 작성해야
한다면 `docs/`에 두고, 디자인 대비비 계산기는 `docs/design-debate/tools/contrast.py`를
사용한다.

## OG 이미지 정책

OG 카드는 1200×630 PNG로 관리한다. 정적 export에서는 이미지 최적화가 동작하지 않으므로
커밋 전에 PNG를 최적화하고, `public/og/`의 모든 카드가 실제 경로에서 200으로 응답하는지
E2E에서 확인한다.

## 확인 방법

```powershell
npm run build
npm run test:e2e
```

E2E는 `out/` 루트의 `README.md`, 비평 문서, 대비비 스크립트, 제거한 단일 OG 카드가
공개되지 않는지도 확인한다.
