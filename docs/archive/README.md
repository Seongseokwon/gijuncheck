## 읽기 전에

- **이 폴더의 내용을 근거로 새 작업을 시작하지 않는다.** 현재 기준은
  `docs/04-실행-우선순위.md`, `docs/09-A안-90일-실행계획.md`, `MEMORY.md`에 있다.
- 여기 적힌 수치·경쟁 판단·제도 설명은 이후 조사에서 정정된 것이 있다.
  인용하려면 반드시 최신 문서·공식 출처와 대조한다.
- 삭제하지 않고 남긴 이유는 **왜 그 결정을 내렸는지**가 필요할 때가 있어서다.
  결정의 배경을 찾을 때만 연다.
