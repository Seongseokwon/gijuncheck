# 광고수익형 사이드프로젝트 — 주제 리서치 결과

작성일: 2026년 7월 30일
대상: 5년차 풀스택 개발자 / 주 20시간 투입 / 겸업 리스크 최소화 필요

---

## 요약

**1순위: 건강보험 피부양자 자격 판정기 + 지역가입자 보험료 시뮬레이터**

조사한 15개 후보 중 **유일하게 "경쟁 도구가 존재하지 않는" 주제**입니다. 검색 1페이지가 전부 공단 신고 서식, 정부24 민원 페이지, 은행·세무법인 설명 블로그입니다. 판정 도구가 없습니다.

RPM도 최상위 구간(건강보험·보험·금융, 10,000~30,000원)입니다.

---

## 1. 스크리닝 결과

기준 세 가지로 걸렀습니다.

1. RPM 상위 카테고리인가 (금융·보험·법률·부동산·세무)
2. 조건 분기가 많아 단순 곱셈으로 안 되는가
3. **1페이지에 제대로 만든 도구가 있는가** ← 실제로 열어서 확인

| 후보 | 기존 도구 | 경쟁 강도 | RPM | 판정 |
|---|---|---|---|---|
| 연봉 실수령액 | 포화 | 최상 | 중 | 탈락 |
| 퇴직금 | 사람인, 고용노동부, 샤플, work.calculate | 최상 | 중 | 탈락 |
| 실업급여 금액 | 사람인, 잡코리아, 고용24, 근로계산기 | 최상 | 중 | 탈락 |
| 프리랜서 3.3% | 삼쩜삼, savingtax, withholding.kr 등 | 최상 | 중 | 탈락 |
| 양도세·취득세 | 부동산계산기.com, findsemusa, mowatool 등 | 높음 | 최상 | 탈락 |
| 스트레스 DSR | 핀다, 부동산계산기.com, NICE지키미 | 높음 | 최상 | 탈락 |
| 국민연금 조기·연기 | mypension.8949ok, npensionprofit, taxcut | 중 | 상 | **3순위** |
| 육아휴직급여 | work.calculate, babycalc, 고용24 (**값이 서로 다름**) | 중 | 중상 | **2순위** |
| **피부양자 자격 판정** | **없음** | **낮음** | **최상** | **1순위** |

### 핵심 발견

**"계산"이 아니라 "판정"인 주제는 아무도 안 만들었습니다.**

계산기를 만드는 사람들은 수식 하나로 끝나는 걸 고릅니다. 조건 트리를 구현해야 하는 주제는 전부 비어 있습니다. 조건 트리는 5년차 개발자에게 어려운 일이 아닙니다. **여기가 차익거래 지점입니다.**

## 2. 1순위 — 건강보험 피부양자 자격 판정기

### 왜 비어 있는가

법령 해석이 필요하고 요건이 자주 바뀝니다. 블로거는 판정 로직을 구현할 수 없어서 글로만 설명하고, 개발자는 이 도메인을 모릅니다.

### 수요층 (넓고 반복적)

- 퇴직·은퇴자 — "지역가입자 되면 보험료 얼마?"
- 프리랜서·사업자등록 고민자 — "등록하면 피부양자 탈락?"
- 직장인 — "부모님 피부양자 등재 가능?"
- 매년 11월 자격 일괄 재산정 시기에 검색 폭증

### 검증된 판정 요건 (2026년 기준)

**소득 요건**

- 연 합산소득 2,000만원 이하
- 2,000만 1원도 초과 시 탈락 (연 합산 기준, 월 기준 아님)
- 사업자등록이 있고 사업소득이 발생하면 금액 무관 탈락

**재산 요건** (재산세 과세표준 기준 — 실거래가·공시가격 아님)

| 과표 구간 | 조건 |
|---|---|
| 5.4억 이하 | 소득 요건만 충족하면 인정 |
| 5.4억 초과 ~ 9억 이하 | 연소득 1,000만원 이하여야 인정 |
| 9억 초과 | 소득 0원이어도 탈락 |

> 참고: 공시가격 10억 ≈ 과표 약 6억. 이 환산을 헷갈리는 사람이 많아 도구의 가치가 큽니다.

**부양 요건** (관계별로 다름 — 여기가 판정 트리의 핵심)

- 형제·자매는 원칙적으로 제외. 예외로 만 30세 미만 또는 만 65세 이상 또는 장애인 + **미혼**일 때만 인정

**탈락 시 보험료 계산식 (2026년)**

```
지역보험료(월) = [소득월액 × 7.19%] + [재산보험료부과점수 × 211.5원]
```

- 2026년 건강보험료율: **7.19%** (2025년 7.09% → 0.1%p 인상)
- 장기요양보험료율: **0.9448%**
- 재산보험료부과점수당 금액: **211.5원**

**임의계속가입 (비교 옵션)**

- 조건: 퇴직 전 18개월 중 직장가입 통산 1년 이상
- 최대 36개월 직장가입자 자격 유지, **재산 미반영**
- 피부양자 등재 가능
- 퇴직 후 90일 내 신고 시 퇴사일로 소급 인정

### 제품 구조 — 3단 퍼널

이게 이 주제의 진짜 강점입니다. 단일 계산기가 아니라 의사결정 흐름입니다.

```
[1단] 피부양자 자격 판정
        ↓ 탈락
[2단] 지역가입자 보험료 자동 계산
        ↓
[3단] 임의계속가입 vs 지역가입자 비교 → 유리한 쪽 제시
```

경쟁자들은 1단도 없고, 공단 도구는 2단만 있으면서 UI가 최악입니다. 3단을 하는 곳은 없습니다.

### 타겟 키워드

주(主) 키워드

- 피부양자 자격 / 피부양자 조건 / 피부양자 등록
- 퇴직 후 건강보험료 / 지역가입자 보험료 계산
- 임의계속가입

롱테일 (판정형 — 도구가 압도적으로 유리한 구간)

- 사업자등록 피부양자 탈락
- 부모님 피부양자 등록 조건
- 피부양자 재산 기준 과세표준
- 형제자매 피부양자 가능
- 연금소득 피부양자 2000만원
- 프리랜서 피부양자 유지

### 애드센스 승인 대비 해설 콘텐츠 (필수)

계산기만 있는 사이트는 "가치 없는 콘텐츠"로 거절되는 사례가 많습니다. 도구별로 해설을 붙이세요. SEO에도 유리합니다 — 도구 페이지엔 외부 링크가 안 붙지만 해설 글엔 붙습니다.

1. 재산세 과세표준을 확인하는 방법 (공시가격과 다른 이유)
2. 피부양자 자격 상실 시점과 소급 부과 구조
3. 임의계속가입이 유리한 조건 / 불리한 조건
4. 사업자등록 전에 반드시 계산해야 하는 것
5. 연금 수령 개시가 피부양자 자격에 미치는 영향
6. 매년 11월 자격 일괄 재산정이란 무엇인가

## 3. 2순위 — 육아휴직급여 계산기 (정확성으로 승부)

기존 도구가 여러 개 있는데도 후보로 남긴 이유는 하나입니다. **기존 도구들이 서로 다른 값을 말하고, 일부는 명백히 틀렸습니다.**

실제 확인한 불일치:

| 사이트 | 사후지급금 서술 | 육아휴직 최대 기간 |
|---|---|---|
| work.calculate.co.kr | "2025.7.1부터 자발적 퇴사 시에도 사후지급금(50%)" | 본문에 **"최대 1년"** (1년 6개월 미반영 — 오류) |
| babycalc.kko-kkuri.com | "전액 지급, 사후 지급 없음 (2025.1.1 시행)" | 1년 6개월 반영 |
| 언론 보도 | "2026년 7월 시행 사후지급금 폐지" | — |

세 출처가 전부 다릅니다. 2025~2026년에 제도가 연달아 개편(상한 250만원 인상, 사후지급금 폐지, 기간 1년 6개월 확대, 6+6 특례)되면서 기존 계산기 대부분이 낡았습니다.

**"정확한 하나"가 되면 이길 수 있는 드문 케이스**입니다. 단, 법령 원문을 직접 읽고 근거를 페이지에 명시해야 합니다.

RPM은 1순위보다 낮지만(육아용품·보험 광고), 검색량과 검색 의도의 명확성은 매우 높습니다.

## 4. 3순위 — 국민연금 조기·연기수령 손익분기점 (건보료 연동)

기존 계산기들(mypension.8949ok.kr, npensionprofit.seosann.kr, taxcut.kr)은 **연금액만** 비교합니다.

그런데 조기수령을 하면 연금액만 바뀌지 않습니다.

- 건강보험 피부양자 자격 (연 2,000만원 기준선에 연금소득 포함)
- 기초연금 수급 여부
- 종합소득세

**이 연동을 계산하는 도구가 없습니다.** 그리고 이건 1순위와 도메인이 겹칩니다.

## 5. 전략적 결론 — 세 개를 하나의 사이트로

1순위·3순위는 같은 도메인(은퇴·소득변동 시 사회보험)이고, 2순위도 인접(고용보험)합니다.

**따로 만들지 말고 하나의 사이트로 묶으세요.** SEO에서 주제 권위(topical authority)가 결정적이고, 내부 링크가 쌓입니다. 계산기 하나짜리 사이트는 순위가 잘 안 오릅니다.

권장 순서:

| 시기 | 작업 |
|---|---|
| 1~2주 | 1순위 판정기 v1 (판정 트리 + 결과 페이지 1개). 디자인은 나중에 |
| 3~4주 | 지역가입자 보험료 계산 붙이기 (2단) |
| 5~8주 | 해설 콘텐츠 6편 → 애드센스 신청 |
| 3~4개월 | 임의계속가입 비교(3단) + 국민연금 연동 |
| 6개월~ | 육아휴직급여 계산기 추가 (별도 섹션) |

## 6. 리스크와 대응

**계산 정확성** — 판정을 틀리면 신뢰가 무너지고 SEO에 치명적입니다.

- 법령 원문(국민건강보험법 시행규칙)과 공단 고시를 직접 확인
- 결과 화면에 근거 조항과 기준 연도를 명시
- "모의 판정이며 법적 효력이 없습니다. 최종 확인은 공단 1577-1000" 면책 문구
- 공단 모의계산 결과와 최소 10케이스 대조 테스트

**법령 변경 추적** — 요건이 매년 바뀌고, 매년 11월 자격 일괄 재산정이 있습니다. 상수를 코드에 흩뿌리지 말고 연도별 설정 객체로 분리하세요. 유지보수가 곧 경쟁력입니다.

**타임라인** — SEO는 6~12개월입니다. 광고수익은 빠른 돈이 아닙니다. 3개월 안에 현금이 필요하면 외주와 병행해야 합니다.

**겸업 리스크** — 이 방향은 선박관리 도메인과 무관해서 경업금지 저촉 가능성이 가장 낮습니다. 다만 근로계약서의 지식재산 귀속 조항은 별도로 확인하세요.

## [codex 피드백]

이 문서는 2026-07-30 시점의 **초기 주제 선정 가설**이며, 현재 실행 기준이나 검증 완료 문서로 사용하면 안 된다. 이후 경쟁 재조사와 코드·공식 자료 대조에서 아래 정정사항이 확인됐다. 다른 AI는 이 문서의 강한 표현을 사실로 재인용하지 말고, 반드시 최신 자료와 직접 대조해야 한다.

### 1. 경쟁 부재 주장은 폐기

- 12행의 `"경쟁 도구가 존재하지 않는"` 주장, 36행의 `기존 도구 없음`, 40행의 `"아무도 안 만들었습니다"`, 110행의 `"경쟁자들은 1단도 없고 ... 3단을 하는 곳은 없습니다"`는 현재 사실과 다르다.
- 2026-07-31 재검색에서 모아툴, 툴허브, 건보계산기, 세금핏, 유리지갑 등 피부양자 판정 또는 건강보험 자격 비교 기능을 제공하는 민간 서비스가 확인됐다.
- 올바른 시장 정의는 `도구가 없는 시장`이 아니라 `최신성·정확성·검산 투명성이 고르지 않고 대표 신뢰 도구가 확립되지 않은 시장`이다.
- 향후 경쟁 조사는 검색엔진, 검색어, 조사일, 상위 결과 범위와 실제 입력 기능 확인 여부를 함께 기록해야 한다. 한 검색어의 1페이지 관찰을 시장 전체의 부재로 일반화하지 않는다.

### 2. SEO·광고 가정은 검증되지 않음

- RPM `10,000~30,000원`, 11월 검색 폭증, 모바일 트래픽 70% 이상, 넓고 반복적인 수요 등은 이 문서 안에 직접적인 데이터 근거가 없다.
- 검색량, CPC/RPM, 계절성, 클릭률은 `[가정]`으로 취급하고 Google Search Console·네이버 서치어드바이저·키워드 도구 또는 실제 배포 데이터로 확인해야 한다.
- 이 프로젝트를 `검색 빈틈의 차익거래`로 정의하지 않는다. 수정된 목표는 `퇴직 전후 건강보험 선택을 공식 기준과 검증 이력으로 설명하는 민간 참고 도구`다.

### 3. 법령·제도 사실 정정

- 93~96행의 임의계속가입 설명 중 `"퇴직 후 90일 내 신고"`는 잘못된 안내다. 2026년 기준 신청기한은 **지역가입자가 된 이후 최초로 고지받은 지역보험료의 납부기한에서 2개월이 지나기 이전까지**다. 공식 근거는 국민건강보험법 및 찾기쉬운 생활법령정보의 `실업자의 직장가입자 자격 유지` 최신 안내로 다시 확인한다.
- `90일`은 피부양자 자격취득 신고의 소급 적용 등 다른 규정과 혼동하지 않는다.
- 이 문서의 `"검증된 판정 요건"`이라는 제목은 과도한 표현이다. 관계별 부양요건, 사업·주택임대·금융소득 예외, 자료 반영 시점은 공식 법령 원문과 공단 안내를 다시 대조해야 한다.

### 4. 보험료 계산은 아직 공개 불가

- `src/lib/constants/2026.ts`의 2026년 건강보험료율 7.19%, 장기요양보험료율 0.9448%, 재산점수당 211.5원은 보건복지부 공식 수치와 일치한다.
- 그러나 `property-score-table.ts`는 공제 후 재산이 0원 이하일 때 현재 22점을 적용하며 `VERIFIED_AGAINST_NHIS = false`다. 전월세 환산도 지원하지 않는다.
- 지역가입자 보험료 계산과 이를 사용하는 임의계속가입 비교는 공단 모의계산 대표 사례 대조와 위 두 항목 확정 전까지 공개하지 않는다.

### 5. 제품 차별점 수정

- `판정 기능의 존재`와 `피부양자→지역보험료→임의계속가입 연결` 자체는 더 이상 독점적 차별점이 아니다.
- 앞으로의 차별점은 다음으로 정의한다.
  1. 관계·동거·혼인·장애·연령·소득 종류·사업자등록·재산을 포함한 정밀 판정
  2. 적용 입력값과 단계별 근거 표시
  3. 공식 출처, 기준연도, 마지막 검토일 공개
  4. 공단 모의계산 대조 건수·입력 사례·오차 공개
  5. 지원하지 않는 조건과 실제 결과가 달라질 수 있는 이유 명시

### 6. 후속 작업 원칙

- 이 문서를 근거로 새 기획을 확장하기 전에 `사실 / 관찰 / 가정 / 결정 / 검증 필요`를 구분한다.
- 비평 문서를 추가하는 데서 끝내지 말고 `비평 → 원문 정정 → 결정 → 구현 → 공식 자료·사례 검증` 순서로 진행한다.
- 정확성 검증보다 디자인, 광고 배치, 신규 계산기 확장을 앞세우지 않는다.
