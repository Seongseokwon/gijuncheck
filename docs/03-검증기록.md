# 검증기록

작성일: 2026-07-31  
공개 안내: `/verification-policy/`

## 목적

이 문서는 기준체크가 어떤 기준을 확인했고, 무엇을 아직 확인하지 못했는지 기록한다.
"검증됨"이라는 표현만 남기지 않고 **출처, 시험 범위, 공식 대조 여부, 공개 상태**를
분리한다. 법령·요율·공단 업무 기준이 바뀌면 이 문서와 코드, 사용자 화면을 함께
갱신한다.

## 상태 정의

| 상태 | 의미 |
| --- | --- |
| 출처 매핑 | 코드의 값·분기에 법령 또는 공단 출처를 연결했다. 출처만으로 실제 계산 결과가 확정됐다는 뜻은 아니다. |
| 자동 테스트 | 경계값과 분기 결과를 테스트로 확인했다. 외부 기관의 결과와 일치한다는 뜻은 아니다. |
| 공식 대조 완료 | 대표 사례를 공단 모의계산 또는 공식 처리 결과와 비교하고, 입력·결과·차이를 기록했다. |
| 비공개 | 공식 대조가 끝나지 않아 사용자에게 계산 또는 비교 결과를 제공하지 않는다. |

## 피부양자 자격 판정

### 출처

- [국민건강보험법 시행규칙(현행) — 제2조, 별표 1, 별표 1의2](https://www.law.go.kr/LSW/lsInfoP.do?ancYnChk=0&chrClsCd=010202&efYd=20260501&lsiSeq=285129&urlMode=lsInfoP)
- [국민건강보험공단 — 피부양자 자격취득 및 상실 신고](https://www.nhis.or.kr/nhis/minwon/minwonServiceBoard.do?mode=view&articleNo=10945798)

### 코드 검증

- 부양요건, 소득요건, 재산요건을 순서대로 판정한다.
- 소득·재산 기준 바로 아래, 기준값, 기준값 초과의 경계값을 단위 테스트에 포함한다.
- 금융소득 1,000만원 문턱, 사업자등록 여부, 형제자매 연령·혼인·동거 조건을 별도 분기로 시험한다.
- 결과에는 입력 요약, 적용 단계, 법령 원문 링크, 민간 참고 서비스 고지를 함께 표시한다.

### 남은 대조 작업

- 대표 관계별로 공단의 실제 안내·신고 처리 기준을 다시 대조한다.
- 소득 자료 반영 시점, 예외·특례, 증빙 필요 여부가 단순 입력 모델과 다른 경우를 기록한다.
- 대조 후에도 개별 심사를 대신할 수 없다는 고지는 유지한다.

## 지역가입자 보험료 계산

### 확인된 범위

- 재산보험료부과점수 60등급표와 기본공제액은 코드와 단위 테스트에 반영돼 있다.
- 근로·연금소득 반영률, 소득보험료율, 장기요양보험료율, 월 보험료 상·하한을 별도 상수로 관리한다.

### 공개를 막는 미확정 항목

1. 기본공제 후 재산이 0원일 때 재산 점수를 1등급 22점으로 볼지 0점으로 볼지 공단 모의계산으로 대조하지 않았다.
2. 전세·월세 평가금액 중 월세 환산 공식을 공식 원문과 대조해 구현하지 않았다.
3. 공식 모의계산과 다음 대표 사례를 비교한 기록이 없다.

| 사례 | 확인 목적 |
| --- | --- |
| 소득 0 · 재산 0 | 공제 후 0원 처리 |
| 기본공제 바로 아래·같음·바로 위 | 재산 공제 경계 |
| 근로·연금소득 조합 | 50% 반영률 |
| 사업·금융·기타소득 조합 | 100% 반영률과 금융소득 문턱 |
| 전세·월세 | 임차주택 평가 |
| 하한·상한 근처 | 보험료 제한 적용 |

공식 대조를 마치면 각 사례의 **대조일, 입력값, 공단 결과, 기준체크 결과, 차이와
처리 이유**를 이 문서에 추가한다. 그 전에는 `VERIFIED_AGAINST_NHIS`를 `true`로
바꾸거나 계산기를 공개하지 않는다.

## 임의계속가입 비교

임의계속가입 비교는 지역가입자 보험료 계산을 전제로 한다. 따라서 지역보험료 공식
대조가 완료되기 전까지 비공개로 유지한다. 신청기한은 퇴직일 기준 고정 일수로
환산하지 않고, 공단의 첫 지역보험료 고지 납부기한을 기준으로 안내한다.

## 갱신 절차

1. 법령·고시·공단 안내의 개정 여부를 확인한다.
2. 코드 상수와 화면 문구, 연결한 출처를 함께 검토한다.
3. 경계값 자동 테스트와 대표 사례 대조를 다시 실행한다.
4. 이 문서에 변경 이유·대조 결과·확인일을 기록한다.
5. 검증 범위가 줄거나 미확정 항목이 생기면 기능을 제한하거나 비공개로 전환한다.

## 한계

이 문서는 내부 구현과 공개 기준을 설명하는 기록이지, 국민건강보험공단의 유권해석이나
법률 자문이 아니다. 최종 자격·보험료·신청 가능 여부는 국민건강보험공단의 심사와
개별 사실관계에 따라 달라질 수 있다.
