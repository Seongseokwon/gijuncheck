# ADR-003: system-ui 중심 폰트 정책

## 결정

이 프로젝트는 Pretendard 웹폰트를 별도 로드하지 않고, 운영체제의 `system-ui` 글꼴을
중심으로 사용한다.

현재 스택은 `system-ui`, macOS·iOS 계열 시스템 글꼴, Windows의 `Segoe UI`, 한국어
환경의 시스템 글꼴 순서다. 외부 CDN이나 `@font-face`, `next/font`를 추가하지 않는다.

## 이유

- 정적 export의 첫 화면에서 추가 폰트 요청과 FOIT/FOUT를 만들지 않는다.
- 한국어 글꼴은 운영체제별 기본 글꼴이 이미 제공하므로 별도 웹폰트 없이도 입력 도구의
  가독성과 모바일 성능을 우선할 수 있다.
- Pretendard를 실제로 사용하려면 파일 라이선스·서브셋·preload·로딩 실패 시 시각 차이를
  함께 운영해야 한다. 현재 서비스 규모에서는 그 비용이 이득보다 크다.

## 재검토 조건

브랜드 글꼴 일관성이 실제 사용성 조사에서 문제로 확인되거나, 운영체제별 한국어 자형
차이가 핵심 지표를 떨어뜨리면 Pretendard를 자체 호스팅하고 서브셋·preload·fallback을
검증한 뒤 별도 ADR로 전환한다.
