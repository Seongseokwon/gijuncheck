**정확한 트래픽 규모나 검색 피크는 확인된 사실이 아니라 가정이다.**
`archive/00-주제-리서치.md`에서 이미 근거 없음으로 정정됐으므로, Search Console 데이터로

## 안전 규칙

1. `ready: false` 기능은 공식 대조가 끝나기 전까지 메뉴·홈·sitemap에 공개하지 않는다.

3. 공단 공식 기준, 직접 대조 결과, 기준체크의 참고 계산을 화면과 문서에서 구분한다.

5. 제도 변경 시 숫자만 수정하지 말고 출처·테스트·설명·검증기록을 함께 갱신한다.
6. 검증되지 않은 경쟁 우위, 검색량, 수익 전망을 사실처럼 문서화하지 않는다.
