# 사대보험 서비스 디자인 방향 제안

작성일: 2026-07-30  
상태: 토론 초안

---

## 1. 결론

이 서비스는 화려한 핀테크 서비스보다 다음 방향이 적합하다.

> **공공기관 수준의 신뢰감과 민간 서비스의 쉬운 사용성을 결합한 생활 행정 도구**

사용자에게 보여줘야 하는 핵심 가치는 “복잡한 보험료를 계산해준다”가 아니라 다음과 같다.

> **복잡한 사회보험 규정을 질문 몇 개로 판정하고, 그 이유와 다음 행동까지 알려준다.**

따라서 디자인의 중심도 계산기, 차트 또는 대시보드가 아니라 **판정 결과와 근거**가 되어야 한다.

---

## 2. 현재 구현에 대한 평가

### 잘된 점

- 화면이 단정하고 광고성 금융 서비스처럼 보이지 않는다.
- 콘텐츠 폭이 적절해 설명과 가이드를 읽기 편하다.
- 입력 컴포넌트의 형태가 일관적이다.
- 헤더와 주요 도구 사이의 이동 구조가 단순하다.
- 판정 결과에 기준 연도와 법적 근거를 표시하는 구조가 준비되어 있다.
- 성공과 탈락 결과를 초록색과 빨간색으로 구분한다.
- 모바일 브라우저의 폼 입력 문제까지 고려되어 있다.
- 피부양자 판정에서 보험료 계산으로 이어지는 사용자 흐름이 구현되어 있다.

### 개선이 필요한 점

- 회색과 흰색 비중이 높아 모든 정보가 비슷한 중요도로 보인다.
- 홈에서 사용자가 무엇부터 해야 하는지 즉시 드러나지 않는다.
- 세 도구가 동일한 카드로 나열되어 실제 이용 순서가 전달되지 않는다.
- 판정 폼이 하나의 긴 행정 서류처럼 느껴질 수 있다.
- 핵심 정보와 보조 설명 사이의 시각적 차이가 작다.
- “왜 이 결과를 믿을 수 있는가”를 보여주는 장치가 부족하다.
- `사대보험`이라는 이름 외에는 기억에 남는 브랜드 자산이 없다.

현재 화면은 기능성과 신뢰성의 뼈대가 좋은 MVP다. 전체를 새로 디자인하기보다 **정보의 우선순위와 서비스 고유의 인상**을 강화하는 편이 적합하다.

## 3. 추천 디자인 콘셉트

### 콘셉트: 생활 행정 내비게이터

보험회사나 금융상품 판매 서비스처럼 보이기보다, 사용자의 상황을 진단하고 다음 행동을 알려주는 서비스로 디자인한다.

디자인 키워드:

- 정확한
- 차분한
- 친절한
- 근거가 보이는
- 과장하지 않는
- 중장년층도 쉽게 사용하는

### 지향하는 인상

- 정부 사이트보다 쉽다.
- 일반 계산기보다 믿을 수 있다.
- 보험회사 사이트처럼 무엇을 판매하려는 느낌이 없다.
- 결과를 단정적으로 과장하지 않고 판단 근거를 명확히 제시한다.

### 지양하는 인상

- 투자 또는 자산관리 대시보드
- 보험상품 비교·판매 서비스
- 캐릭터 중심의 가벼운 생활 앱
- 법령 원문을 그대로 옮긴 행정 사이트

## 4. 디자인 원칙

### 원칙 1. 결과가 디자인의 주인공이다

이 서비스에서 가장 중요한 화면은 입력 폼이 아니라 결과 화면이다.

결과는 다음 순서로 보여주는 것이 좋다.

1. 최종 판정
2. 핵심 이유
3. 사용자가 해야 할 다음 행동
4. 단계별 판정 내역
5. 적용 기준과 근거
6. 주의사항

### 원칙 2. 도구보다 사용자의 상황을 먼저 보여준다

사용자는 “지역가입자 보험료 계산기”라는 기능명보다 자신의 상황을 먼저 인식한다.

예:

- 퇴직을 앞두고 있어요.
- 사업자등록을 고민하고 있어요.
- 부모님을 피부양자로 올리고 싶어요.
- 연금 수령을 시작할 예정이에요.

홈 화면에서는 기능 목록과 함께 이런 상황별 진입점을 제공하는 것이 좋다.

### 원칙 3. 중요한 숫자와 결론은 크게, 근거는 가까이 둔다

결론을 크게 보여주되 판단 근거를 별도 페이지나 깊은 팝업에 숨기지 않는다.

### 원칙 4. 신뢰를 장식이 아니라 정보로 만든다

공공기관을 연상시키는 장식이나 색상을 모방하기보다 다음 정보를 명확히 보여준다.

- 적용 기준 연도
- 마지막 기준 확인일
- 판정에 사용된 조건
- 입력 정보 저장 여부
- 법적 효력에 관한 주의사항
- 최종 확인 방법

### 원칙 5. 중장년 사용자를 기본 사용자로 가정한다

작고 옅은 글자, 복잡한 제스처, 숨겨진 메뉴를 최소화한다.

## 5. 색상 방향

현재 슬레이트 계열을 유지하면서 브랜드 색상 하나를 추가하는 것이 적합하다.

| 용도 | 제안 색상 | 역할 |
|---|---:|---|
| 주 색상 | `#17324D` | 헤더, 제목, 주요 브랜드 요소 |
| 행동 색상 | `#087E8B` | 버튼, 링크, 진행 상태 |
| 기본 배경 | `#F5F8FA` | 차분한 페이지 배경 |
| 성공 | `#16865C` | 자격 인정, 통과 |
| 주의 | `#B7791F` | 확인 필요, 참고 |
| 탈락 | `#C2414B` | 요건 미충족 |

국민건강보험공단의 로고나 색상 체계를 직접 모방해서는 안 된다. 공식 기관처럼 오인되지 않으면서도 신뢰감이 있어야 한다.

판정 상태는 색상만으로 표현하지 않는다.

- `✓ 유지 가능성이 높습니다`
- `! 추가 확인이 필요합니다`
- `× 소득요건을 충족하지 못합니다`

## 6. 홈 화면 제안

### 6.1 첫 화면

현재 문구인 다음 표현은 서비스 전체 정의로는 좋다.

> 소득이 바뀔 때 내 사회보험은 어떻게 바뀌나

하지만 첫 행동을 유도하기에는 다소 추상적이다. 현재 가장 완성도가 높은 피부양자 판정을 중심으로 첫 화면을 구성하는 방안을 제안한다.

#### 제목 예시

> 피부양자 자격,  
> 혼자 판단하기 어렵다면

#### 설명 예시

> 관계·소득·재산 정보를 입력하면 2026년 기준으로 자격 가능성과 탈락 사유를 알려드립니다.

#### 대표 버튼

> 피부양자 자격 확인하기

#### 버튼 아래 신뢰 정보

> 약 3분 · 회원가입 없음 · 입력 정보 저장 안 함

### 6.2 상황별 시작

대표 판정 버튼 아래에 사용자의 상황을 기준으로 진입점을 제공한다.

| 사용자 상황 | 연결할 콘텐츠 |
|---|---|
| 퇴직을 앞두고 있어요 | 피부양자 판정 또는 임의계속가입 안내 |
| 사업자등록을 고민하고 있어요 | 피부양자 판정과 사업자등록 가이드 |
| 부모님을 피부양자로 올리고 싶어요 | 부모 관계가 선택된 피부양자 판정 |
| 연금 수령을 시작할 예정이에요 | 연금 영향 가이드와 피부양자 판정 |

### 6.3 세 도구의 관계

현재 세 도구는 독립적인 메뉴라기보다 하나의 의사결정 과정에 가깝다.

```text
1. 피부양자 가능 여부 판정
              ↓ 탈락
2. 지역가입자 예상 보험료 계산
              ↓ 비교
3. 임의계속가입과 금액 비교
```

홈에서는 이를 단순 카드 목록이 아니라 **내 상황 확인 과정**으로 보여주는 것이 좋다.

## 7. 판정 입력 화면 제안

### 한 화면 입력 원칙은 유지한다

현재 코드에 정의된 “입력은 한 화면에 제공한다”는 원칙에 동의한다. 페이지를 여러 단계로 나누면 전체 입력량을 알 수 없고 중간 이탈이 늘어날 수 있다.

다만 현재 하나의 큰 `대상자 정보` 카드 안에 모든 입력이 들어가 있어 긴 서류처럼 느껴질 수 있다. 페이지를 전환하지 않으면서 시각적으로 세 구역을 만든다.

1. 누구를 등록하려 하나요?
2. 연간 소득은 얼마인가요?
3. 재산과 사업자등록 상태를 확인하세요.

각 구역은 번호, 짧은 설명, 구분선 또는 옅은 배경으로 구분한다.

### 추가하면 좋은 요소

- 상단에 `약 3분 소요` 표시
- 금액 입력 예시 제공
- 입력하지 않은 금액은 0원으로 처리된다는 안내
- 소득 종류별 짧은 도움말
- 합산소득을 현재보다 눈에 띄게 표시
- `입력 내용은 저장하거나 서버로 전송하지 않습니다` 안내
- 모바일 화면 하단에 판정 버튼 고정
- 사용자가 잘못 이해하기 쉬운 재산세 과세표준에 설명 링크 제공

### 금액 입력 예시

```text
근로소득
[ 12,000,000                    원 ]
지난해 원천징수영수증의 총급여가 아닌 소득금액 기준
```

실제 판정 기준에 맞는 설명 문구는 별도로 검증해야 한다.

## 8. 결과 화면 제안

결과 화면에 가장 높은 디자인 우선순위를 배정해야 한다.

### 자격 인정 예시

```text
✓ 피부양자 자격이 인정될 가능성이 높습니다

입력한 정보를 기준으로 부양·소득·재산요건을 모두 충족합니다.

[판정에 사용된 정보 확인]
```

### 탈락 예시

```text
× 소득요건을 충족하지 못합니다

합산소득이 연간 기준 2,000만원을 130만원 초과했습니다.

[예상 지역보험료 확인하기 →]
```

### 단계별 판정

```text
✓ 부양요건      통과
× 소득요건      기준 초과
— 재산요건      판정 불필요
```

현재 구현은 각 단계의 메시지와 근거를 이미 제공하므로, 정보 구조를 새로 만들기보다 시각적 계층을 강화하면 된다.

### 결과 화면에서 중요한 표현 원칙

- `가능합니다`보다 `가능성이 높습니다`를 사용한다.
- 탈락 여부뿐 아니라 초과한 기준이나 원인을 보여준다.
- 다음 행동을 대표 버튼 하나로 제시한다.
- 상세 근거는 결과 바로 아래에 둔다.
- 주의사항은 결론과 시각적으로 구분하되 숨기지 않는다.

## 9. 타이포그래피와 간격

중장년 사용자와 모바일 인앱 브라우저를 고려해 현재보다 본문과 라벨을 조금 키우는 편이 좋다.

| 요소 | 권장 크기 |
|---|---:|
| 기본 본문 | 16px |
| 폼 라벨 | 15~16px |
| 보조 설명 | 최소 13~14px |
| 페이지 제목 | 28~32px |
| 결과 핵심 문장 | 24~28px |
| 주요 금액 | 32px 이상 |

본문 줄 간격은 약 `1.6~1.7`이 적합하다.

보조 설명에 너무 밝은 회색을 사용하면 실제 모바일 환경에서 읽기 어렵다. 중요하지 않은 정보라도 사용자가 입력을 이해하는 데 필요하다면 충분한 대비를 유지해야 한다.

## 10. 브랜드 요소

초기 단계에서는 별도의 복잡한 로고보다 간단한 워드마크가 적합하다.

### 제안

- `사대보험` 텍스트 워드마크 유지
- 체크 표시, 분기 또는 판정표를 연상시키는 작은 심볼 추가 가능
- 대표 색상은 네이비 또는 청록 하나만 강하게 사용
- 아이콘은 선형 스타일로 통일

캐릭터나 대형 일러스트는 현재 서비스의 신뢰성과 어울리지 않으며 필수 요소도 아니다.

## 11. 피해야 할 디자인

- 보험회사처럼 보이는 푸른 그라데이션과 가족 사진
- 캐릭터 중심의 지나치게 가벼운 디자인
- 모든 정보를 대시보드와 차트로 표현하는 방식
- 입력 과정을 여러 페이지로 쪼개는 긴 위저드
- 중요한 법령 설명을 툴팁과 모달에 과도하게 숨기는 방식
- 결과보다 입력 폼이 더 강조되는 구성
- 과도한 애니메이션
- `100% 정확`, `확실히 보장` 같은 표현
- 공공기관 공식 서비스로 오인될 수 있는 디자인

## 12. 제안 우선순위

### 1단계: 정보 계층 개선

1. 홈에 대표 판정 CTA 추가
2. 홈에 상황별 시작 카드 추가
3. 세 도구를 연속된 의사결정 과정으로 표현
4. 입력 폼을 관계·소득·재산의 세 구역으로 분리
5. 결과 화면의 판정·이유·다음 행동 계층 강화

### 2단계: 시각 체계 개선

1. 네이비와 청록 기반 브랜드 색상 도입
2. 타이포그래피 크기와 대비 개선
3. 버튼, 카드, 상태 표시 컴포넌트 정리
4. 신뢰 정보 표현 방식 통일

### 3단계: 사용성 개선

1. 모바일 하단 판정 버튼
2. 입력 항목별 도움말
3. 상황별 기본값 또는 쿼리 연결
4. 결과 공유 또는 인쇄 기능 검토

## 13. 토론이 필요한 결정

### 질문 1. 홈의 중심을 무엇으로 둘 것인가?

**제안:** 초기에는 `피부양자 자격판정`을 대표 서비스로 전면에 둔다.

대안:

- 사대보험 전체를 포괄하는 허브로 유지
- 세 도구를 동등하게 노출
- 사용자 상황별 진입만 제공

### 질문 2. 한 화면 폼을 어디까지 유지할 것인가?

**제안:** 페이지 전환은 하지 않되 세 개의 시각 구역으로 나눈다.

대안:

- 현재처럼 하나의 카드 유지
- 실제 3단계 위저드로 변경
- 기본 질문만 먼저 보여주고 조건에 따라 펼치기

### 질문 3. 브랜드 톤을 얼마나 공공 서비스에 가깝게 할 것인가?

**제안:** 신뢰감은 가져오되 공식 기관을 모방하지 않는다.

대안:

- 행정 서비스에 가까운 보수적 디자인
- 토스 같은 친근한 금융 서비스
- 전문 세무·법률 도구 같은 문서 중심 디자인

### 질문 4. 판정 결과를 얼마나 단정적으로 표현할 것인가?

**제안:** 결론은 명확하게 보여주되 `가능성이 높습니다`, `입력 기준으로 판단됩니다`처럼 한계를 함께 표현한다.

### 질문 5. 주요 사용 연령을 어디에 둘 것인가?

**제안:** 40~60대 당사자와 부모를 대신해 확인하는 30~40대를 함께 고려한다.

이 결정에 따라 글자 크기, 설명량, 모바일 우선순위가 달라질 수 있다.

## 14. 최종 의견

현재의 절제된 스타일은 버리지 않는 것이 좋다. 이 서비스에는 화려함보다 정확성과 신뢰가 중요하다.

다만 현재 화면은 모든 요소가 비슷한 강도로 표현되어 있어 서비스의 핵심인 **판정, 이유, 다음 행동**이 충분히 강조되지 않는다.

따라서 다음 세 가지 변화가 가장 중요하다.

1. **상황 중심의 홈**
2. **부담이 적게 느껴지는 입력 구조**
3. **결론과 다음 행동이 강한 결과 화면**

이 서비스가 지향해야 할 모습은 “예쁜 보험 계산기”가 아니다.

> **결론과 근거를 차분하고 명확하게 알려주는 사회보험 판정 서비스**
