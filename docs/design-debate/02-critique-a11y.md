| 하단 고정 제출 버튼 vs 홈 인디케이터(세이프에어리어) | 명시 없음 | 확인 불가 |

### 실패 항목

- 입력 테두리 대비 1.47:1 (기준 3:1 대폭 미달) — 필드 경계가 백색 배경 위에서 사실상 보이지 않는다. 저시력·야외 눈부심 환경에서 "여기가 입력칸이다"를 인지하지 못할 수 있다.
- 접힌 설명·힌트 13px — 보조설명 최소 14px 미달.
- 푸터/면책 12px — 보조설명 최소 14px 대비 2px 미달. 면책 문구가 가장 작은 글자로 처리되어 있다.

### 측정 불가 항목

- 입력 필드 실제 텍스트 크기 미기재 — 16px 미만이면 iOS Safari 인앱 브라우저에서 포커스 시 화면이 확대되고 원상복귀되지 않는 버그가 발생한다. 이 문서는 라벨 크기(15px)만 명시했을 뿐 입력값 자체의 폰트 크기를 특정하지 않았다.
- "한 줄 요약 이유" 텍스트 크기 미기재.
- 제출 버튼 폭, "?" 아이콘, 토글 등 인터랙티브 요소의 정확한 px 크기 다수 미기재.
- 하단 고정 버튼의 세이프에어리어(홈 인디케이터) 처리 여부 미기재.
- 필수 입력 수(11개 중 정확히 몇 개가 필수인지), 오류 발생 시 포커스 이동 지점, 이탈 후 재진입 시 입력값 유지 여부 — 모두 문서에 없음.

### 실패 항목

- 힌트/근거텍스트가 두 배경 모두에서 4.5 기준 미달(4.29:1, 4.48:1)이며, 동시에 13px로 크기 기준(14px)도 미달 — 이중 실패.
- 빌드상태 "검증 중" 배지 대비 4.33:1(기준 4.5 미달), "준비 중" 배지 대비 3.12:1(기준 대폭 미달) — 이 두 배지는 이 안의 핵심 기능(4개 영역의 진행 상태를 한눈에 보여주는 것)을 수행하는 요소인데, 12px 크기(기준 14px 미달)와 겹쳐 실사용 환경에서 사실상 판독 불가능하다.
- 본문/설명 텍스트 14px — 이 안 자체가 "본문"으로 명명한 텍스트가 본문 최소 기준(16px)에 미달.
- 근거·조항·힌트 통합 텍스트 13px, 상태 배지 12px — 보조설명 최소 14px 각각 미달.

### 측정 불가 항목

- 입력 필드 실제 텍스트 크기 미기재(iOS 자동확대 리스크).
- 홈의 진입 라우터·도메인 카드·헤더 내비게이션 등 인터랙티브 요소의 정확한 px 크기(터치 타겟) 다수 미기재.
- 주요버튼 크기(width/height) 미기재.
- "준비 중" 카드의 "점선 회색 테두리" 정확한 hex 미기재 — 대비 계산 불가.
- 필수 입력 수, 오류 발생 시 복귀 지점, 이탈 후 재진입 시 값 유지 여부 미기재.

### 측정 불가 항목

- 입력 필드 실제 텍스트 크기 미기재(iOS 자동확대 리스크, 3개 카드 모두 해당).
- 각종 링크·버튼·모바일 각주 앵커의 터치 타겟 px 미기재.
- 계산식·수치표(14px)와 본문(16px) 모두 각 기준의 정확히 최소치에 있어 여유가 0 — 디스플레이·렌더링 편차에 취약할 수 있으나 이는 px 기준 자체의 특성상 별도 "여유" 수치화는 불가하므로 결함이 아닌 주의 사항으로만 기록.
- 필수 입력 수, 오류 발생 시 복귀 지점, 이탈 후 재진입 시 값 유지 여부 미기재.
