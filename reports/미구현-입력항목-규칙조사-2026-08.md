# 미구현 입력 항목 규칙 조사 (2026-08-06)

공단 지역보험료 모의계산 화면에는 있는데 기준체크가 받지 않는 입력 3개.
B안 구현 전 규칙 확인 단계의 결과다.

**결론 먼저: 1번은 구현 가능하다. 2번은 계산식이 미확정이라 아직 못 한다. 3번은 미확인이다.**

## 1. 농어촌 지역 거주 경감 — **확정. 구현 가능**

출처: [국민건강보험공단 「지역 건강보험료 경감」](https://www.nhis.or.kr/static/html/wbma/b/wbmab0301.html) (공단 공식 안내)
법령 근거: 국민건강보험법 제75조제1항제1호 · 시행령 제45조제2호 · 시행규칙 제46조제2호 · 「보험료 경감고시」 제4조

### 요건과 경감률

| 항목 | 내용 |
|---|---|
| 대상 | 군 및 도농복합 형태 시의 **읍·면지역에 거주**하는 **사업소득 500만원 이하** 세대 |
| 예외 | 사업소득 500만원 **초과**라도 **농어업인으로 등록된 가입자가 있으면** 적용 |
| 추가 대상 | 동의 녹지지역·준농어촌지역에 거주하는 **농어업인 세대** |
| 적용 방법 | **주민등록 주소지로 일괄 적용** (별도 신청 없음) |
| 경감률 | **22%** |

### 필요한 입력

**체크박스 1개** — 「읍·면지역에 거주합니다」.
사업소득은 이미 받고 있으므로 500만원 조건은 자동 판정된다.

농어업인 등록 여부까지 받을지는 선택이다. 받지 않으면 사업소득 500만원 초과 농어업인
세대에서 경감이 빠져 **보험료를 과대 계산**한다. 체크박스 하나 더 추가하는 비용이 작으므로
같이 받는 편이 낫다고 본다.

### 아직 확인 못 한 것

- **경감이 건강보험료에만 붙는가, 장기요양보험료에도 붙는가.**
  장기요양은 건강보험료에서 환산하므로 자동으로 따라올 가능성이 높지만 확인 필요.
- **하한·상한과 경감의 적용 순서.** 경감 후 하한 미만이 되면 어떻게 되는가.
- 공단 계산기가 실제로 22%를 어디에 적용하는지 (화면에 `farmFishResultOne`,
  `farmFishResultTwo` 라는 전용 결과 행이 숨겨져 있는 것을 DOM에서 확인했다)

→ 공단 모의계산 3~4건이면 전부 답이 나온다.

### 범위 경계 — 다른 경감은 넣지 않는다

같은 공단 페이지에 세대별 경감이 여럿 있다(65세 이상·70세 이상·한부모·장애인·만성질환·
55세 이상 여자 단독세대, 각 10~30%). **섬·벽지는 50%, 농어업인은 0~28%.**

그러나 **공단 모의계산기 자신이 이것들을 반영하지 않는다.** 화면 상단에 그렇게 적혀 있다:

> 보건복지부의 「보험료 경감 고시」에 따른 경감(노인, 장애인, 한부모 등) … 사유로
> 실제 납부하는 보험료와는 차이가 있을 수 있습니다.

계산기가 반영하는 경감은 **농어촌 하나뿐**이다. 우리 목표가 "공단 모의계산과 일치"이므로
범위도 여기까지다. **나머지 경감은 구현 대상이 아니라 한계로 표시할 대상이다.**

## 2. 주택금융부채 공제 — **요건은 확정, 계산식 미확정**

출처: [국민건강보험공단 「주택금융부채 건강보험료 공제 한눈에 보기」](https://si4n.nhis.or.kr/popup/2021/20220628_pop01longdesc.html)

### 확정된 요건

| 항목 | 구입(자가) | 임차 |
|---|---|---|
| 대상자 | 지방세법 시행령 제110조의2상 **1세대 1주택자** | **1세대 무주택자**로 전월세 평가금액이 보험료에 반영되는 자 |
| 대상 주택 | **공시가격 5억원 이하** | **전월세평가금액 1.5억원 이하** |
| 대상 대출 | 담보대출·보금자리론 | 전세자금대출·전세자금(보증서·질권)대출·전세보증금담보대출 |
| 부채 인정 | 취득일 또는 전입일 중 빠른 날부터 **전후 3개월 이내** 대출 | 입주일과 전입일 중 빠른 날부터 **전후 3개월 이내** 대출 |
| 신청 | **가입자 신청 필요** (일괄 적용 아님) | 같음 |

※ 여기서 1세대는 주민등록법상 비동거배우자와 만 19세 미만 자녀를 포함한다.

### 미확정 — 이게 구현을 막는다

**공제액 계산식이 자료마다 다르다.**

| 자료 | 평가율 | 공제 한도 |
|---|---|---|
| 2023년 공단 웹진 | 주담대 **70%** / 보증금담보 **30%** | — |
| 2022년 개정 보도자료 요약 | 자가 **60%** / 임차 **30%** | 1주택 과표 5,000만원 / 무주택 1.5억원 |
| 시행령 별표4 인용문(검색) | — | 기본공제 **5,000만원** · 점수당 **208.4원** |

**세 번째가 결정적이다 — 기본공제 5,000만원과 208.4원은 낡은 수치다.** 현행은 기본공제
1억원, 점수당 211.5원(2026)이다. 즉 **저 인용문 자체가 옛 버전이므로 공제 한도
5,000만원도 현행이라 볼 수 없다.**

법제처 원문(시행령 별표4)은 자동 조회가 되지 않았다(JS 렌더링).

### 필요한 입력 (계산식 확정 시)

- **주택 보유 형태**: 무주택 / 1세대 1주택 / 그 외 — **기존 「임차 중」 체크박스를 대체**
- **대출잔액** 금액
- (1주택인 경우) 주택 공시가격 — 5억원 이하 요건 판정용

> 지금 화면의 「주택·건물을 소유하지 않고 임차 중입니다」 체크박스가 이 3분류로 바뀐다.
> **재산을 5칸으로 쪼갤 필요는 없다.** 전월세 억제 규칙도 이 분류로 그대로 표현된다.

### 다음에 할 일

1. 시행령 별표4 **현행 원문** 확보 (법제처 화면 직접 열기)
2. 공단 모의계산으로 평가율·한도 실측 — 주택 과표 고정 후 대출잔액을 올려가며 점수 변화 관찰

## 3. 분리과세 주택임대소득 — **미확인**

공단 화면에 **소득 칸으로 별도** 존재한다. 도움말은 "해당 귀속년도에 발생한 전체 금액을
입력해주세요"뿐이고 반영률을 말하지 않는다.

확인해야 할 것:

- **반영률이 사업소득 등(100%)과 같은가 다른가.** 별도 칸으로 받는 데는 이유가 있을 것이다
- 필요경비·기본공제를 뺀 금액인가, 총수입금액인가
- 우리 `Income` 타입에 필드를 추가해야 하는가, `business`에 합쳐도 되는가

**주의:** 피부양자 판정에서 주택임대소득은 별개 규칙이다 — 사업자등록 여부와 무관하게
주택임대소득이 있으면 피부양자가 될 수 없다(`docs/03` 참조). 지역보험료의 이 칸과
혼동하지 말 것.

→ 공단 모의계산 2건(1,000만원을 이 칸 vs 사업소득 등 칸)이면 반영률이 바로 나온다.

## 조사가 중단된 이유

공단 모의계산 서버가 우리 요청에 응답을 멈췄다. `retrieveLocalCalcAjax.do` POST가
pending에서 넘어가지 않는다. 짧은 시간에 40건 이상 자동 입력한 것이 원인으로 보인다.

**남은 실측(농어촌 적용 지점, 주담대 평가율, 주택임대소득 반영률)은 시간을 두고 재개한다.**
한 번에 몰아서 돌리지 말고 사례 사이에 간격을 두는 편이 낫다.

## 권고

**농어촌 경감부터 구현한다.** 요건과 경감률이 공단 공식 문서로 확정됐고, 필요한 입력이
체크박스 하나이며, 금액 영향(22%)이 셋 중 가장 크다. 남은 미확인 사항(장기요양 적용
여부, 하한과의 순서)은 실측 3~4건이면 끝난다.

**주담대 공제는 계산식을 확보하기 전까지 시작하지 않는다.** 요건만 알고 구현하면
1세대 1주택 판정 로직만 만들어두고 정작 공제액을 못 넣는다. 시행령 별표4 현행 원문이
선행 조건이다.

**주택임대소득은 실측 2건으로 판단한다.** 반영률이 100%로 같다면 `business`에 합쳐도
되므로 입력 추가 없이 안내 문구만 고치면 될 수도 있다.
