Core Web Vitals 미측정. Chrome 확장이 이 세션에 연결되지 않아 LCP / INP / CLS / TTFB를 수집하지 못했다. 정적 export + Vercel CDN, 공유 JS 103KB 구성이라 구조적 위험은 낮아 보이지만 이는 추정이지 측정이 아니다. INP는 랩 데이터로 잡히지 않으므로 PageSpeed Insights의 CrUX 필드 데이터를 함께 봐야 한다.

llms.txt 운영 응답 미확인. 빌드 산출물에는 4,116바이트로 존재하나 운영 URL 페치에서 본문이 비어 돌아왔다. 다만 Google Search는 llms.txt를 읽지 않으므로(2026-07 공식 문서) 순위·AI Overviews 영향은 없다. 확인해야 하는 이유는 GEO가 아니라 정적 자산 배포 정합성이다.
